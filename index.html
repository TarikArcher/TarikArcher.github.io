What makes a movie popular?

An analysis of IMDb movie data that explores how ratings, audience interest, genre, runtime, and release period relate to each other.

The goal is to identify the patterns behind movies that earn high ratings and strong audience engagement, and to see how those patterns have changed over time.

Python · Jupyter Notebook

View notebook on GitHub Open in Colab

Questions the analysis answers

  • How do IMDb ratings relate to audience votes?
  • How does audience interest differ across genres?
  • How do average ratings differ across genres?
  • How has movie runtime changed over time?
  • What rating patterns show up across decades?
  • Do highly rated movies also draw substantial audience engagement?

Component Inventory Tracker

An Excel-based inventory system that organizes inventory items, component relationships, and costs. It shows how much money is sitting in storage and how long components wait before shipping.

Receiving and shipping logs update stock automatically, and each component is flagged Fresh, Watch, Aging, or Old based on how long its oldest stock has been on hand.
